# Historial de cambios

## [1.0.0] - 2026-11-18

- Aplicación de escritorio con navegación rápida, diagnóstico y controles para iniciar y detener Nox.
- Instaladores y ediciones portables para Windows y Linux x64 con Node.js y Python incluidos.
- Vinculación de WhatsApp Web mediante un perfil de navegador persistente por usuario.
- Perfiles de proveedores locales y remotos, búsqueda de modelos y prueba de generación.
- Prompt del sistema, fuentes de referencia y selección de conversaciones autorizadas.

Verificación inicial en Linux y Windows mediante Wine. La vinculación en Windows nativo y la generación real con proveedores de nube siguen pendientes.
